01 / Kenali bagiannya

Enam bagian, satu kerja sama.

Komputer bekerja dengan menerima data, mengolahnya sesuai instruksi, lalu menampilkan hasil.

Input

Tempat data dan perintah masuk. Contoh: mengetik angka melalui keyboard.

Memori

Menyimpan data dan instruksi sementara agar dapat digunakan saat proses berlangsung.

CPU

Pusat pemrosesan komputer. Di dalamnya, CU dan ALU bekerja sama mengolah data.

CU · Control Unit

Mengatur urutan kerja: mengambil instruksi dan memberi arahan kepada bagian lain.

ALU · Arithmetic Logic Unit

Mengerjakan perhitungan aritmatika dan operasi logika di dalam CPU.

Output

Tempat hasil pengolahan disajikan. Contoh: jawaban muncul pada layar.

Perangkat input: keyboard, mouse, mikrofonPerangkat output: monitor, speaker, printer
02 / Peta proses

Diagram IPO: dari perintah ke hasil

IPO berarti Input → Process → Output. Pada tahap Process, CPU membaca data dari Memori; CU mengatur pekerjaan dan ALU menghitung.
